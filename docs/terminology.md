# Terminology map — EN / DE / FR

Binding term map for the project's multilingual documentation. English (EN)
is canonical. German (DE) and French (FR) usage follows this map and
`docs/management_summary.md`; if a deviation is found, reconcile it here
first, then in the documents.

Languages / Sprachen / Langues: [README (EN)](../README.md) ·
[README (DE)](../README.de.md) · [README (FR)](../README.fr.md)

## Rules

1. EN is canonical. Each translated file carries the standard 3SM
   frontmatter plus `language`, `translation_of` (the EN original) and
   `source_updated` (date of the EN version it reflects), and a
   language-switcher line at the top linking the language trio.
2. Official names of acts, ordinances and institutions are used as
   officially published and are **never re-translated** (tables below).
   Unverified roles stay flagged in all languages (e.g. BBL).
3. SR numbers, CELEX numbers, article cites (DE: Art. 2 Bst. a Ziff. 1;
   FR: art. 2 let. a ch. 1), thresholds, dates and code lists (HS, CN,
   CAS/EC) are identical across languages.
4. Diagrams and code stay in English.
5. Scope: tranche 1 covers README, METHODOLOGY and DATA_SOURCE (DE/FR).
   Planning, design and implementation documents remain EN-only.
