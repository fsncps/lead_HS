# Unit v0.1.2 — Design delta: operator layer (make, CLI operability, report routing)

## Abstract

The Design for unit v0.1.2 on top of the v0.1.1 `leadhs` tool.
Strategy fixed what and why (10_STRATEGY/v0.1.2.md; MASTER
D21/D22/D25/D26); this file fixes the technical how: the exit-code
enforcement and DB-initialization preflight in `cli.py`, the repo-root
`Makefile` (one target per `leadhs` call, `GO=1` guard), report routing
(`data/report/` → `docs/report/`), `--data-dir` for installed use, and
the housekeeping that rides along. With **D26 (2026-09-11) the unit
also closes M0**: it completes the census for every register row
through the operator layer and structures the census report (D25) —
including a small metrics migration (0003) for the per-HS count
metrics (OD-A, resolved below). No new pipeline stages, no new
`leadhs` commands.

## CLI contract deltas (od2–od4; binding via interfaces.md i10/i11)

- `main()` rewritten: `cli(standalone_mode=False)`;
  `click.exceptions.Exit` → its code; `UsageError` → 1 ("Error: …"
  + "Try 'leadhs --help' for help."); other `ClickException` →
  `exc.show()` + its code; `Abort` / `KeyboardInterrupt` → 130
  ("interrupted"); anything else → `bug:` + 1 (`LEADHS_DEBUG`
  re-raises). Commands keep `ctx.exit(n)`.
- All four groups gain `no_args_is_help=True` (bare `leadhs`, `db`,
  `source`, `probe` → help, exit 0).
- `list_` registered via `@source.command("list")`; the
  `source.add_command(list_, name="list")` line is deleted — one
  registration, the derived `list-` artifact is gone.
- `doctor`: the `--no-net` option is removed (was a no-op
  `default=True`); only `--net` remains (`doctor.main(rt, net=net)`).
- `--data-dir DIR` added to the root group: sets
  `db_path = DIR/leadhs.sqlite`; mutually exclusive with `--db`
  (`UsageError` → 1). The raw store follows `dirname(db_path)/raw`
  (`Runtime.store_root` unchanged).
- Unused `field` import dropped.

## DB initialization preflight (od3; interfaces.md contract)

`_ensure_initialized(ctx, rt)` in `cli.py`; called by `db status`,
`db audit`, `source load`, `source list`, `probe run`, `probe record`,
`probe report`. Checks: file exists and is non-empty, then the
`schema_version` table is present. On failure:

    error: database not initialized — run `make setup` (repo) or
    `leadhs db init` then `leadhs source load` first

Exit 1. `db init` is the only initializer and does not preflight.

## Makefile (full recipe text — od1, od5, od6)

```make
# lead_HS — operator entrypoint (v0.1.2). One target = one `leadhs` call;
# pipeline logic lives in the CLI (D21); make stays a thin wrapper.
# Parameters are make variables until M1 (committed config file).

.PHONY: help install doctor db-init db-status db-audit sources-load \
	sources-list setup probe-dry probe-single record report \
	report-publish probe census test smoke test-net clean clobber \
	frame sample acquire ingest parse analyze full
.DEFAULT_GOAL := help

PYTHON      ?= python3
DB          ?= data/leadhs.sqlite
MODE        ?= census
SAMPLE      ?= 5
SOURCE      ?=
REPORT_DIR  ?= data/report
PUBLISH_DIR ?= docs/report

export LEADHS_CONTACT
export LEADHS_DEBUG

LEADHS = leadhs --db $(DB)

help: ## self-documenting index
	@grep -hE '^[a-zA-Z_-]+:.*##' $(MAKEFILE_LIST) | \
	  sed -E 's/^([a-zA-Z_-]+):.*## *(.*)$$/  \1  \2/' | sort

install: ## editable install into the active interpreter
	$(PYTHON) -m pip install -e .

doctor: ## environment preflight
	$(LEADHS) doctor

db-init: ## apply pending migrations (backup taken by default)
	$(LEADHS) db init

db-status: ## applied/pending migrations, row counts
	$(LEADHS) db status

db-audit: ## provenance rules R1–R9 + raw-store orphans
	$(LEADHS) db audit --unreferenced

sources-load: ## upsert register from src/leadhs/dict/sources.csv
	$(LEADHS) source load

sources-list: ## list registered sources
	$(LEADHS) source list

setup: install db-init sources-load doctor ## first-run: install + init + load + doctor (idempotent)

probe-dry: ## census plan; zero network
	$(LEADHS) probe run --all --dry-run

probe-single: ## probe one source (SOURCE=CS-1)
	$(LEADHS) probe run --source $(SOURCE) --mode $(MODE) --sample $(SAMPLE)

record: ## manual finding (SOURCE= METRIC= VALUE=|VALUE_TEXT= [UNIT=] [URL=] [NOTE=])
	$(LEADHS) probe record --source $(SOURCE) --metric $(METRIC) \
		$(if $(VALUE),--value $(VALUE)) \
		$(if $(VALUE_TEXT),--value-text "$(VALUE_TEXT)") \
		$(if $(UNIT),--unit $(UNIT)) \
		$(if $(URL),--url "$(URL)") \
		$(if $(NOTE),--note "$(NOTE)")

report: ## render md/csv/json into $(REPORT_DIR)
	@mkdir -p $(REPORT_DIR)
	$(LEADHS) probe report --format md   --out $(REPORT_DIR)/probe-report.md
	$(LEADHS) probe report --format csv  --out $(REPORT_DIR)/probe-report.csv
	$(LEADHS) probe report --format json --out $(REPORT_DIR)/probe-report.json

report-publish: ## stage one report into $(PUBLISH_DIR) (WHICH=…; copies, never moves)
	@test -n "$(WHICH)" || { echo "report-publish: set WHICH=path/to/report" >&2; exit 1; }
	@test -f "$(WHICH)" || { echo "report-publish: no such file $(WHICH)" >&2; exit 1; }
	@mkdir -p $(PUBLISH_DIR)
	cp "$(WHICH)" "$(PUBLISH_DIR)/$$(basename "$(WHICH)")"
	@echo "staged $$(basename "$(WHICH)") into $(PUBLISH_DIR)/ — committing is explicit"

guard-%:
	@test "$(GO)" = "1" || { echo "$*: set GO=1 to confirm (GO=1 make $*)" >&2; exit 1; }

probe: guard-probe ## real census over all active sources (GO=1)
	$(LEADHS) probe run --all --mode $(MODE) --sample $(SAMPLE)

census: guard-census setup probe report db-audit ## setup → probe → report → audit (GO=1; guard runs before setup)

test: ## offline suite (net/mdbtools markers deselected)
	$(PYTHON) -m pytest

smoke: ## end-to-end fixture smoke (2am-Friday test)
	$(PYTHON) -m pytest tests/test_cli_smoke.py

test-net: ## opt-in real-network checks
	$(PYTHON) -m pytest -m net

clean: ## remove caches and build artifacts
	rm -rf build/ .pytest_cache/ .benchmarks/
	find . -type d -name __pycache__ -prune -exec rm -rf {} +

clobber: guard-clobber ## wipe local state (GO=1 + typed 'yes')
	@echo "clobber: this deletes the database and the raw store — type 'yes' to confirm"
	@read -r confirm; test "$$confirm" = "yes" || { echo "aborted"; exit 1; }
	rm -f "$(DB)" "$(DB)-wal" "$(DB)-shm"
	rm -rf data/raw data/backups $(REPORT_DIR)

# M1–M4 stubs — fail loudly with a pointer (strategy U6)
frame sample acquire ingest parse analyze full:
	@echo "error: '$@' is milestone-gated (M1–M4) — see 10_STRATEGY/ARCHITECTURE.md rollout" >&2
	@exit 1
```

Key semantics: `guard-%` is a **prerequisite**, so it fires before any
recipe side effect; `census` lists `guard-census` first, so `setup`
(pip install) never runs without GO=1. All recipe values are
shell-quoted. `report-publish` copies and prints the commit reminder
(U5). `.gitignore` gains `build/`, `.pytest_cache/`, `.benchmarks/`.

## Report routing (od5)

## DECISIONS (unit-level design)

- od1: make = thin-wrapper entrypoint; params as vars until M1;
  `guard-%` GO=1 prerequisite on probe/census/clobber; census guard
  precedes setup; clobber adds a typed `yes`.
- od2: exit-code enforcement in `main()` (standalone_mode=False;
  UsageError → 1; Abort/interrupt → 130; Exit → its code).
- od3: `_ensure_initialized` preflight — guided error, exit 1, never
  `bug:`.
- od4: `source list` single registration; `--no-net` removed; groups
  `no_args_is_help`; `--data-dir` exclusive with `--db`.
- od5: report routing via make — intermediates `data/report/`,
  `report-publish` copies to `docs/report/`.
- od6: `.gitignore` additions (build/, .pytest_cache/, .benchmarks/).
- od7: tests — operability, preflight, make-wiring (`-n`/guarded only);
  wheel-build verification in-unit.
- od8: census report content per D25 — structured per-source
  metadata + cross-source summary matrix; "source feasibility"
  framing; run status/notes visible.
- od9 (OD-A): per-HS count metrics via migration 0003 INSERT
  (hs3208_count/hs3209_count/hs3213_count, numeric) — not deferred
  to M1 (D25 mandates them in this unit's report).
