# Overview

Documentation-only research study of the **EU market** for paints and
varnishes (HS/CN 3208 solvent-borne, 3209 water-borne; 3213 artists'
colours as a low-priority annex): how many products the market holds, for
how many of them detailed documentation (SDS) is obtainable, and what that
documentation shows about lead — situated in the autonomous Swiss
Cassis-de-Dijon regulatory frame (THG Art. 16a, VIPaV exceptions
catalogue, ChemRRV lead ban). Switzerland is the regulatory frame only,
never a studied market (D31); the study takes no position on the
regulation. Tool side: `leadhs`, a single-user stdlib-first Python CLI
(≥ 3.11; click/requests/beautifulsoup4/jinja2) over one SQLite evidence
database plus a hash-addressed raw-document store — no servers, no lab,
no paid data sources, minimal cost. Deliverables: documented market
numbers + a reusable product/SDS evidence database. The directory appears
as `robin_HS` and `lead_HS`; the GitHub remote is `lead_HS` — same project.

## Security

- Raw store: hash-only filenames + source-id allowlist (path-traversal
  guard, `store.py`); all SQL parameterized (P4); no secrets in the DB.
- Network: robots.txt respected per domain, ≥ 2 s spacing (source robots
  Crawl-delay honored where larger — BASTA 10 s), honest UA with contact
  (`LEADHS_CONTACT`), no browser impersonation, no bulk hammering, no
  account/agreement signups (D4).
- No credentials/env values in planning docs, reports, or the database.

## Policies

- Flaky tests: none known; network tests are opt-in markers, never flaky
  by construction (injected clock).
- Golden files: regenerate only with explicit review (report output
  changes are intentional changes).
- Load/stress: not applicable at current scale (~1M-row ceiling stated;
  SQLite portable-SQL hedge per RAW_SOURCING R1).

- **Product data only** in tool, database and reports — no legal-category
  dimension, no legal-status fields, no legal-text documents (D27,
  supersedes D14). Legal context lives in study documentation.
- **Provenance on every record**: source URL + retrieval date + raw hash;
  audit rules R1–R9 enforced by `db audit`; P1–P7 binding write contract.
- **Report routing**: renders → `data/report/` timestamped per run
  (nothing overwritten; "latest" copies refreshed); publishing →
  `docs/report/` is an explicit act and stages timestamp-hash snapshots.
  `docs/management_summary.md` (DE/FR) is never overwritten by generated

- **Numbers from the DB only**: every reported number cites run_key/seed;
  never a typed literal (P7; the v0.2.2 principle "every number is a
  query result").

  drift markers (D23); planning docs EN-only; binding term map
  `docs/terminology.md`.
- **Documentation-tree split (D41, 2026-09-18)**: public study detail
  lives in `docs/study/` (METHODOLOGY, DATA_SOURCE, LEAD_SDS, DATA_MODEL,
  ARCHITECTURE, translations, charts); plan-tree topic files stay slim
  concept summaries.

  against the ECHA EC inventory.
- **Register growth discipline**: new sources enter as documented rows;
  `data_sources.csv` grows only via the de5 gate (probe-confirmed bulk +
  identity tuple + in-scope filter); gated registers never enter on
  claims (de6).
- **Frontmatter** (`unit`, `stage`, `lifecycle`, `updated`) on all 3SM

# Domain notes

- Customs nomenclature: only **11 CN8 codes** under 3208+3209 — the
  nomenclature cannot count products; product identity = (manufacturer,
  manufacturer product-ident), UFI/GTIN as cross-references (D33).
- Regulatory seam: Swiss ban ≥ 0.01% total Pb (ChemRRV Anhang 2.8) sits
  **below** the EU SDS declaration floor 0.1% → the 100–1000 ppm band is
  method-invisible (D15 headline caveat).
- Lead in paints: chromates (no lawful EU supply since 17 Mar 2022),
  red-lead primers (documented niche), artists' lead whites (documented
  NL/IT), lead driers in alkyds — presence undocumented (top open
  empirical question).
- Source classes: CS (statistics), PE (web channels), ST (statistical/
  register sources), AS (associations & registers), LI (literature);
  register 108 rows; exactly two confirmed bulk sources today
  (`data_sources.csv`: AS-2 ECAT 17,013 distinct, AS-3 Nordic Swan
  2,322 distinct; BASTA pinned 195,391 articles / 1,925 companies but
  de5 not met — paint filter open).
- Milestones: M0 probe (done) → M1 frame/sample → M2 acquire/parse →
  M3 corroborate/analyze → M4 report; frame/sampling machinery is
  designed-ahead but unbuilt.
